# 项目文档导航

本文档目录把产品、设计、开发、测试、发布和使用说明分开，避免同一事实在多个文件中互相冲突。

| 文档 | 用途 | 权威范围 |
|---|---|---|
| [PRD](../PRD.md) | 用户需求、V1 范围和验收标准 | 产品行为的唯一依据 |
| [技术设计](../TECHNICAL_DESIGN.md) | 进程、存储、检索、翻译、PDF、安全和数据结构 | 已实现的技术基线 |
| [开发计划](../DEVELOPMENT_PLAN.md) | M0～M11 的原始执行顺序和门禁 | 计划与历史任务拆分 |
| [实施状态](../IMPLEMENTATION_STATUS.md) | 当前完成度、最终测试结果和外部验收边界 | 当前交付状态 |
| [Apache-2.0 许可证](../LICENSE) | 项目自有源码的使用、修改和分发条件 | 开源许可 |
| [开发指南](DEVELOPMENT.md) | 全新克隆、依赖、运行、测试和目录结构 | 开发者入口 |
| [发布指南](RELEASE.md) | 版本、构建、安装冒烟和 Release 附件 | 发布者入口 |
| [用户说明](USER_GUIDE.md) | 安装后的检索、PDF、翻译、缓存和排错 | 最终用户入口 |
| [WoS 导入说明](WOS_IMPORT_GUIDE.md) | 从学校正常登录的 WoS 导出并导入 | 合规导入流程 |
| [需求追踪](TRACEABILITY.md) | PRD 范围到实际代码测试的映射 | 回归审计 |
| [低保真页面线框](images/low-fidelity-wireframes.png) | 首次启动、首页、搜索、详情、期刊、知识库和设置的早期交互参考 | 设计历史，不覆盖当前实现 |
| [M0 基线](M0_BASELINE.md) | 目标 Windows 与原生依赖兼容性记录 | 技术预检历史 |
| [ADR](adr/README.md) | 不宜只写在代码中的重大架构决定 | 决策历史 |

发生冲突时，产品范围以 PRD 为准，当前实现事实以代码、自动化测试和实施状态为准。修改行为时，应在同一变更中同步相应文档和测试。
