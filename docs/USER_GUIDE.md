# 催化文献用户说明

## 1. 启动与退出

双击桌面“催化文献”快捷方式后，App 会启动仅监听 `127.0.0.1` 随机端口的本地服务，并打开默认浏览器。刷新页面或重启电脑不会丢失已保存资料。关闭全部 App 标签页后约两分钟，本地服务、OCR 和翻译子进程会一并退出。

若重复双击快捷方式，第二次启动只会打开正在运行的实例，不会创建第二套数据库。

## 2. 配置免费检索来源

在“设置”中按需填写：

- Web of Science Starter API Key：主检索通道。是否可申请及具体额度由 Clarivate 当前政策决定。
- OpenAlex 免费 API Key：补充元数据与开放摘要；不配置时 App 会明确显示来源不可用。
- Crossref 联系邮箱：用于 polite pool，不是账号或密钥。

密钥使用当前 Windows 账户的 DPAPI 加密。App 不接收学校账号、密码、验证码或 MFA 信息，也不模拟学校登录。

如果学校只允许网页访问 WoS，请在浏览器中正常登录后，从 WoS 官方页面导出 Plain Text、RIS 或 `.xlsx` 文件，再到“导入 WoS 记录”上传。预览确认前不会写入知识库。

## 3. 检索与知识库

“检索”可按主题、题名、作者或 DOI 查询。每个来源单独显示成功、缓存、缺少 Key、限额或失败状态；单个来源失败不会伪装成完整结果。

结果可以加入知识库、喜欢、设置未读/在读/已读，或上传 PDF。知识库支持多分类、标签、普通笔记、本地全文检索，以及 BibTeX、RIS、CSV 导出。

## 4. PDF 入库与阅读

上传上限为 250 MB、5000 页。App 会先在隔离进程中验证 PDF，再计算 SHA-256：

- 二进制完全相同：关联已有文件，不增加物理副本。
- DOI 相同但文件不同：提示关联或保留其他版本。
- 题名、作者、年份弱匹配：只提示，由用户决定。

普通页面直接提取文字；扫描页面使用 PP-OCRv6；混合 PDF 逐页决定，不会把整本文件一律 OCR。原 PDF 复制到本地知识库后，即使删除原下载位置仍可阅读。

阅读器支持连续滚动、页码、缩放、缩略图、目录、全文搜索、高亮、划线和批注。批注记录在数据库中，不修改原 PDF；更换文件版本后旧批注会标记为可能失效。

## 5. 本地翻译

翻译使用腾讯 Hy-MT2-1.8B `Q4_K_M` GGUF 和 llama.cpp，仅翻译题名与摘要。首次下载约 1.13 GB，App 会显示来源、大小和许可证并要求明确确认。模型校验 SHA-256 后才会加载；翻译完成或空闲后模型进程退出。

模型文件属于永久资料，不计入 500 MB 缓存。用户可维护固定译法和“不翻译”词表。

## 6. 推荐、关注和提醒

研究主题、正负关键词和期刊关注都可编辑或停用。推荐按主题命中、关注期刊、作者、年份以及已明确的喜欢/收藏/阅读状态评分，并为每篇显示真实原因。关闭行为推荐后，历史状态仍保留，但不再参与评分。

保存检索和期刊检查只在 App 打开期间运行，不注册 Windows 后台任务，不发系统通知或邮件。同一结果会记录为已见，避免重复提醒。每日自动检查有 1–50 次的本地上限；外部来源返回限额后会停止并在提醒中心说明。

## 7. 数据、缓存和备份

默认目录：

    %LOCALAPPDATA%\CatalystLiterature\
      data\core.db          设置、文献、译文、笔记、批注
      data\cache.db         可删除缓存索引
      library\pdfs\        永久原始 PDF
      models\               永久翻译/OCR 模型
      backups\              数据库备份，不含 PDF
      logs\                 脱敏轮转日志

缓存目标为 450 MB、硬上限为 500 MB，按最近最少使用清理。清理缓存不会删除数据库、PDF、模型或已保存译文。

重要：内置备份不含 PDF。若电脑或硬盘损坏，PDF 可能无法恢复；如资料重要，请在 App 外自行备份整个数据目录。

## 8. 故障处理

- 启动失败：查看 `%LOCALAPPDATA%\CatalystLiterature\runtime\startup-error.html` 和 `logs\app.log`。
- 某来源失败：查看结果页来源状态；检查网络、Key 和免费额度，其他本地功能仍可用。
- PDF 缺失：App 会按原 SHA-256 验证重联文件，内容不一致时拒绝错误关联。
- 翻译模型校验失败：重新下载模型；App 不会加载大小或哈希不符的文件。
- 后台未退出：确认没有 App 标签页；等待约两分钟后在任务管理器检查 `CatalystLiterature.exe`、`llama-server.exe`。

诊断清单不包含 API Key、会话令牌、PDF 正文、摘要或笔记正文。
