# Web of Science 官方记录导入说明

1. 在浏览器中打开 Web of Science，由本人通过学校提供的正常入口登录。
2. 完成检索后选择需要的记录，并选择“导出”。
3. 字段选择“完整记录”或至少包含题名、作者、来源、年份、DOI、摘要和入藏号。
4. 优先导出 Plain Text；App 也支持 RIS 和 `.xlsx` Excel。
5. 在 App 的“导入 WoS 记录”页面选择文件，先查看新增、重复、缺 DOI、字段冲突和错误记录，再确认写入。

App 不保存学校账号、密码、Cookie 或登录页面内容，也不会模拟登录或抓取 WoS 网页。原始导出文件只在导入时读取，不复制到本地知识库。`AB` 字段作为摘要，`UT` 作为 WoS 唯一号，`DI` 作为 DOI。重复导入不会创建重复文献。
